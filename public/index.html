Deployable to Render in Minutes

This repository includes everything required for zero-configuration deployment to Render with persistent MongoDB Atlas integration.

1

Configure BotFather

Create your bot with /newbot on Telegram BotFather and copy your TELEGRAM_TOKEN.

2

NVIDIA API & Mongo

Get your API key from NVIDIA build portal and create a free MongoDB Atlas M0 cluster URI.

3

Deploy to Render

Connect your GitHub repo to Render as a Web Service. The included render.yaml auto-provisions the service.
